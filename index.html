01 TOPIC: คำนำ Paired (Linear vs Cosine Lr)

โปรเจกต์นี้นำเสนอการเปรียบเทียบโมเดล AI ทั้ง 2 ตัว โดยทำการ train ด้วย Learning Rate ที่แตกต่างกัน ได้แก่ Linear Lr และ Cosine Lr เพื่อประเมินประสิทธิภาพการเรียนรู้ภายใต้ชุดข้อมูลเดียวกัน

องค์ประกอบหลัก

  • Train: กระบวนการฝึกสอนโมเดล AI
  • Test: ชุดข้อมูลสำหรับทดสอบประสิทธิภาพ
  • Lr: อัตราการเรียนรู้ (Learning Rate)

วัตถุประสงค์การวิเคราะห์

เปรียบเทียบค่า Confidence เชิงสถิติรายคู่ (Paired comparison) ระหว่างการปรับ Learning Rate สองรูปแบบ เพื่อค้นหาแนวทางที่ให้ประสิทธิภาพสูงสุด

05-A PAIRED DESIGN & HYPOTHESIS

การออกแบบการวิเคราะห์แบบจับคู่ (Paired Design) บนหน่วยสังเกตเดียวกันจำนวน 912 คู่ข้อมูล

สมมติฐานทางสถิติ

  • H0: ค่ากลางของผลต่าง = 0
    (ทั้งสองโมเดลให้ผลลัพธ์ไม่แตกต่างกัน)
  • H1: ค่ากลางของผลต่าง ≠ 0
    (ทั้งสองโมเดลให้ผลลัพธ์แตกต่างกัน)
H0: μ~D=0
H1: μ~D≠0

ทำไมถึงใช้ Wilcoxon Test?

  • วิเคราะห์ข้อมูลแบบจับคู่ (Paired Design) จำนวน 912 คู่ข้อมูล
  • เนื่องจากข้อมูล "ไม่มีการแจกแจงแบบปกติ" (Non-normal)
  • จึงไม่สามารถใช้ Paired t-test ได้ ต้องใช้สถิตินอนพาราเมทริก (Non-parametric) ตัวนี้แทน

05-B R SCRIPT & CONSOLE OUTPUT

ผลการตรวจสอบการแจกแจงของข้อมูลและการทดสอบสมมติฐานด้วย Wilcoxon Test

R Script (คำสั่ง)

attach(DATA_1)

# 1. ตรวจสอบการแจกแจงปกติ
shapiro.test(Linear_Confidence)
shapiro.test(Cosine_Confidence)

# 2. ทดสอบความแตกต่างด้วย Wilcoxon
wilcox.test(Linear_Confidence, Cosine_Confidence, paired=TRUE)

Console (ผลลัพธ์)

> shapiro.test(Linear_Confidence)
W = 0.71235, p-value < 2.2e-16
# p-value < 0.05 ➔ ข้อมูลไม่แจกแจงแบบปกติ

> shapiro.test(Cosine_Confidence)
W = 0.79717, p-value < 2.2e-16
# p-value < 0.05 ➔ ข้อมูลไม่แจกแจงแบบปกติ

> wilcox.test(Linear, Cosine, paired=TRUE)
V = 284033, p-value < 2.2e-16
alt. hypothesis: true location shift is not equal to 0

06 INFERENCE (ผลการทดสอบ Wilcoxon Paired Test)

ผลลัพธ์จากการรันคำสั่งใน RStudio พร้อม continuity correction (N = 912 คู่)

  • Wilcoxon Statistic (V): 284,033
  • P-value: < 2.2e-16 (มีนัยสำคัญทางสถิติสูงมาก)
  • Alternative Hypothesis: True location shift is not equal to 0

ข้อสรุป ปฏิเสธสมมติฐานหลัก (H0) ยืนยันว่า Linear และ Cosine ให้ค่า Confidence แตกต่างกันอย่างมีนัยสำคัญ
